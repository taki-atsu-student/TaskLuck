# TaskLuck

TaskLuck は、飲食店・小売店舗向けのシフト管理・タスク管理・人事運用を一つの画面で扱うための Web アプリケーションです。React/Vite ベースのフロントエンド、Node.js/Express ベースのバックエンド、MongoDB を接続して動作します。店長・社員・アルバイトそれぞれの役割に応じて、ダッシュボード、シフト作成、タスク割り当て、ガチャ型タスク配布、店舗設定などを利用できます。

## 1. できること

### 主要機能
- ログイン
  - ユーザー ID とパスワードでログインできます。
  - 画面左のサイドバーからユーザー情報の確認やパスワード変更ができます。
- ダッシュボード
  - 本日のシフト、担当タスク、タスク消化率、XP/レベル、ランキングを表示します。
  - 店長向けには全体の進捗とランキング、アルバイト向けには個人の XP とレベル進捗が見えます。
- シフト管理
  - カレンダー形式でシフトを表示します。
  - 希望シフトの提出、シフト作成、定休日・人手不足の表示、PDF 出力に対応します。
  - 店長またはスタッフ権限のあるユーザーがシフトを作成できます。
- タスク管理
  - タスクの追加・編集・削除、担当割り当て、優先度・ステータス管理ができます。
  - タスクをプール化してドラッグ & ドロップで移動できます。
  - フィルター・ソート機能で一覧を絞り込めます。
- ガチャ機能
  - 「闇鍋ガチャ」によりランダムにタスクを引き当てられます。
  - 進行中・承認待ちの状態に応じて完了申請や承認フローに遷移します。
- 店舗設定
  - 営業時間、定休日、時間帯ごとの最低人数、勤務ルール、特別営業日・臨時休業を設定できます。
- スタッフ管理
  - スタッフ一覧、役割、XP、レベル、給与、時給、追加時給の管理ができます。
- 通知
  - タスク承認依頼や通知内容を表示し、既読管理とアクション実行ができます。

## 2. 使用技術

### フロントエンド
- React 19
- Vite 6
- TypeScript
- Tailwind CSS（設定ファイルあり。ただし主要スタイリングは独自 CSS ベース）
- React Router 風の画面切り替えはなく、状態ベースでページ切り替えを実装

### バックエンド
- Node.js
- Express 5
- MongoDB + Mongoose 8
- CORS / Morgan / dotenv
- serverless-http により AWS Lambda / API Gateway 連携にも対応

### 主要ライブラリ
- jsPDF: シフト表の PDF 出力
- AWS Amplify / AWS SDK: 認証・AWS 連携周りの準備

## 4. 必要環境

- Node.js 18 以上を推奨

- MongoDB がローカルで起動できること
- 可能なら Docker やローカル MongoDB インスタンス

## 5. 起動方法

### 5.1 環境変数の設定

サーバー側の環境ファイルを作成します。

```bash
cp server/.env.example server/.env
```

作成した server/.env では、次の値を設定します。

```env
PORT=5001
MONGODB_URI=mongodb://127.0.0.1:27017/taskluck
```

- `MONGODB_URI` はローカル MongoDB の接続先です。
- 接続先を変える場合は、実際の MongoDB URL に置き換えてください。

### 5.2 依存関係のインストール

ルートディレクトリで次を実行します。

```bash
npm install
```

### 5.3 開発サーバーの起動

```bash
npm run dev
```

このコマンドで、フロントエンドとバックエンドが同時に起動します。

### 5.4 アクセス先

- フロントエンド: http://localhost:5173
- バックエンド: http://localhost:5001
- デプロイ済みバックエンド: https://yhcfr2u9hg.execute-api.ap-northeast-1.amazonaws.com

## 6. 利用可能なコマンド

### ルート
- `npm run dev`: フロントエンドとバックエンドを同時起動
- `npm run build`: フロントエンドのビルド
- `npm run start`: バックエンドを起動

### クライアント
- `npm run dev --workspace client`: Vite の開発サーバー起動
- `npm run build --workspace client`: 本番ビルド
- `npm run preview --workspace client`: ビルド結果のプレビュー

### サーバー
- `npm run dev --workspace server`: Express サーバー起動
- `npm run start --workspace server`: Express サーバー起動

## 7. API の概要

バックエンドは主に以下の API を提供します。

- `/api/tasks`: タスク管理
- `/api/users`: ユーザー管理
- `/api/shifts`: シフト管理
- `/api/shift-patterns`: シフトパターン管理
- `/api/business-info`: 店舗情報・営業時間・ルール管理
- `/api/staff`: スタッフ情報管理
- `/api/gacha`: ガチャ用タスク生成・実行
- `/api/gacha-settings`: ガチャ設定
- `/api/approval`: タスク承認
- `/api/notifications`: 通知管理

## 8. 画面ごとの UI の特徴

### ログイン画面
- ロゴ、ユーザー名、パスワード入力欄を持つシンプルなログイン画面です。
- Enter キーでもログインできます。

### ダッシュボード
- 日付表示、タスク進捗バー、今日のシフト、役割別の統計、ランキングをカード形式で表示します。
- 店長向けには組織全体の進捗、アルバイト向けには XP とレベル表示が強調されます。

### シフト画面
- 月表示のカレンダーと、選択した日付のシフト一覧を見られます。
- 定休日・人手不足・自分のシフトが視覚的に区別されます。
- 管理者はシフト作成ボタン、PDF 出力ボタンを利用できます。

### タスク画面
- タブ切り替えで「すべて」「進行状況」「完了」を切り替えられます。
- 絞り込み条件、ソート、プール化、ドラッグ & ドロップでタスク管理を行います。
- 役割に応じて「開始」「完了申請」「承認」「却下」の操作が表示されます。

### ガチャ画面
- タスクをランダムに引くための演出があり、履歴も表示されます。
- 承認待ちや進行中のタスクに応じてボタンの表示が変化します。

### 店舗設定画面
- 勤務ルール、時間帯別最低人数、曜日別営業時間、特別休業設定を一覧で編集できます。
- 変更内容は保存・キャンセル操作で管理できます。

### スタッフ管理画面
- 総スタッフ数、社員数、アルバイト数の統計を表示します。
- スタッフを選択すると、名前・パスワード・給与・追加時給・XP・レベルの編集ができます。

## 9. 開発時のメモ

- サーバー起動時に MongoDB への接続を試み、接続できるまで待機します。
- 開発時は CORS を許可しているため、フロントエンドから API を呼び出しやすい構成です。
- 画面遷移は URL ベースではなく、アプリ内状態で切り替える構造です。
- 既存の UI はカード・モーダル・オーバーレイを多用する管理画面寄りのデザインです。
- サーバー側には AWS Lambda 向けのエントリポイントも実装されており、サーバーレス環境への展開にも対応しています。

## 10. もしトラブルがあったら

- MongoDB が起動していない: `MONGODB_URI` の接続先を確認してください。
- フロントエンドが API に繋がらない: バックエンドが `5001` ポートで起動しているか確認してください。
- 依存関係の不整合: ルートディレクトリで `npm install` を再実行してください。
- 環境変数が反映されない: `server/.env` の内容を再確認してください。
